# FinTech: Data, Risk, and Digital Assets

Course website maintained by Rainy1993.

- Course home: https://rainy1993.github.io/fintech-course/
- Current lesson: https://rainy1993.github.io/fintech-course/a2/
- Data and runnable Python examples can be downloaded from the lesson page.

This repository contains the website publication files. Course content continues
to be maintained in the original local CourseDesign course folder. Run its
`course_site/publish_site.py` to refresh this publication copy before uploading.

GitHub Pages publishes `main` from the repository root. `.nojekyll` preserves
the static files. Python examples run on students' computers.
