02 · From an investor’s return to log returns

Janni bought one BTC on 1 July 2026. Assuming he paid that day’s average of USD 59,345 and values it at the 2 July average of USD 61,045, his return on 2 July is:

Simple price return
rt=(Pt − Pt−1) / Pt−1
r2 Jul=(61,045 − 59,345) / 59,345
≈+2.865%
Janni asks: What was the price return from 1 to 3 July?

For a long price series, multiplying many growth factors is cumbersome. Can we use a measure that adds across time?

Log returns are common in financial time-series analysis because they add exactly over time. That convenience does not make them identical to an investor’s simple percentage return. Chris Brooks, Introductory Econometrics for Finance, Box 1.3 explains this time-additive property.

"""Reproduce a FinTech course figure.
Install: python -m pip install numpy pandas matplotlib scipy
For data examples, save avg_price_per_day.csv beside this script.
"""
from pathlib import Path
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# Read the same 93 BTC prices used by the website.
data_file = Path(__file__).with_name("avg_price_per_day.csv")
if not data_file.exists():
    data_file = Path(__file__).resolve().parent.parent / "data/avg_price_per_day.csv"
data = pd.read_csv(data_file, usecols=["Date", "BTC"], parse_dates=["Date"])
data = data.loc[data["Date"].between("2026-04-07", "2026-07-08")].sort_values("Date")
prices = data["BTC"].to_numpy(dtype=float)
dates = data["Date"].to_numpy()
g = 100 * np.diff(np.log(prices))  # Log returns in percentage points.

# Match the website's editable settings.
BINS = 10
BANDWIDTH = 0.70  # Percentage points; not scipy's bandwidth factor.
LAYER = "hist"  # "hist", "kde", or "normal".
low, high = np.floor(g.min() - 1), np.ceil(g.max() + 1)
edges = np.linspace(low, high, BINS + 1)
x = np.linspace(low, high, 400)
# Gaussian KDE with an absolute bandwidth in return percentage points.
z = (x[:, None] - g[None, :]) / BANDWIDTH
kde = np.exp(-z*z/2).mean(axis=1) / (BANDWIDTH*np.sqrt(2*np.pi))
mu, sd = g.mean(), g.std(ddof=1)
normal = np.exp(-0.5*((x-mu)/sd)**2) / (sd*np.sqrt(2*np.pi))
fig, ax = plt.subplots(figsize=(8, 4.5))
density = LAYER != "hist"
ax.hist(g, bins=edges, density=density, color="#7bb1d2", alpha=0.7,
        rwidth=0.98, label="Histogram")
if LAYER in ("kde", "normal"):
    ax.plot(x, kde, color="#0e8d84", label="KDE")
if LAYER == "normal":
    ax.plot(x, normal, color="#c87229", linestyle="--", label="Normal benchmark")
ax.set(xlabel="Daily log return (%)",
       ylabel="Density per percentage point" if density else "Frequency (days)")
ax.legend()

plt.tight_layout()
plt.show()
Definition: A histogram counts observations within equal-width return ranges called bins.
Advantage: Shows which return ranges occurred most often in the observed period.
Bins: Too few can hide detail; too many can produce a jagged picture with empty bins.
Limitation: An empty bin means no return fell in that range in this sample—not that a future return cannot.

In view 1, bar height counts days. In views 2 and 3, each bar is rescaled to density: count ÷ (92 × bin width in percentage points). The bar area represents the observed share in that range, so bars and curves can share one vertical scale. KDE is estimated from these observations; the normal curve uses this sample's mean and standard deviation. With 92 returns, tail comparisons are exploratory.

The next question: Can past BTC log returns help predict the next return?

Do BTC log returns have serial correlation?

Autocorrelation function (ACF)
ACF(k)=Corr(gt, gt−k)
≈n∑t=k+1 (gt − ḡ)(gt−k − ḡ)n∑t=1 (gt − ḡ)²

k = days apart (1 = yesterday) · ḡ = sample mean · n = number of returns.

No-memory benchmarkgt = μ + εt · μ = constant mean · εt = daily surpriseACF(k) ≈ 0 for k ≥ 1
Lag 1 · yesterday → today

"""Reproduce a FinTech course figure.
Install: python -m pip install numpy pandas matplotlib scipy
For data examples, save avg_price_per_day.csv beside this script.
"""
from pathlib import Path
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# Read the same 93 BTC prices used by the website.
data_file = Path(__file__).with_name("avg_price_per_day.csv")
if not data_file.exists():
    data_file = Path(__file__).resolve().parent.parent / "data/avg_price_per_day.csv"
data = pd.read_csv(data_file, usecols=["Date", "BTC"], parse_dates=["Date"])
data = data.loc[data["Date"].between("2026-04-07", "2026-07-08")].sort_values("Date")
prices = data["BTC"].to_numpy(dtype=float)
dates = data["Date"].to_numpy()
g = 100 * np.diff(np.log(prices))  # Log returns in percentage points.

from scipy.stats import chi2

MAX_LAG = 1  # Choose from 1 to 12, as on the website.
n = len(g)
centered = g - g.mean()
# Whole-sample denominator: same ACF estimator as the website and NIST.
acf = np.array([centered[k:] @ centered[:-k] / (centered @ centered)
                for k in range(1, MAX_LAG + 1)])
lags = np.arange(1, MAX_LAG + 1)
q = n * (n + 2) * np.sum(acf**2 / (n - lags))
p_value = chi2.sf(q, df=MAX_LAG)  # No fitted ARMA parameters here.
fig, ax = plt.subplots(figsize=(8, 4))
ax.bar(lags, acf, color="#2167a0")
guide = 1.96 / np.sqrt(n)
ax.axhline(0, color="grey", linewidth=0.8)
for bound in [-guide, guide]:
    ax.axhline(bound, color="#b6a46b", linestyle="--")
ax.set(xlabel="Lag (calendar days)", ylabel="ACF", xticks=lags)
print(f"n = {n}; lag-1 ACF = {acf[0]:.3f}")
print(f"Ljung–Box through lag {MAX_LAG}: Q = {q:.2f}; p = {p_value:.4f}")

plt.tight_layout()
plt.show()

Bars: + same direction · − opposite direction · 0 little linear relation. Dashed guide: ±1.96/√n, where n = observed returns (rough, one lag at a time).

Ljung–Box test · lags 1 through 1

Null hypothesis: the autocorrelation is zero at every selected lag.

Qh = n(n + 2) h∑k=1 ACF(k)²n − k

h = last selected lag; n = observed returns. Q combines the squared ACF bars from lag 1 to h; larger Q means more evidence against the null.
