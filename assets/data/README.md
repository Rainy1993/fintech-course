# Course data

Data source: [Blockchain Research Center](https://blockchain-research-center.com).

`avg_price_per_day.csv` is the full course dataset. The lesson uses its BTC daily average prices in USD from 7 April to 8 July 2026.

`btc_daily_average_2026-04-07_2026-07-08.csv` is the 93-day BTC extract used by the lesson charts.
